# Paint Canvas 计划

本文件跟踪尚未完成的产品能力。已实现能力不在此重复列为待办；实现前仍需结合当前架构和测试要求评估范围。

## 待修改

- 元素隐藏与展示：节点类型已有 `visible` 字段，但尚未接入节点 UI 映射、图层面板控制及缩略图验证。
- 图片属性：位置和宽高已使用通用属性面板；补充图片专属属性（例如裁切/适配方式或资源替换）前，先明确支持的图片编辑语义。
- 动画编辑：已有淡入、淡出、移动、旋转等预设和动画列表；补充完整的关键帧时间轴、路径动画前，先定义帧编辑、预览和持久化体验。
- 特效属性：补充蒙层/遮罩、阴影/内外阴影、渐变和滤镜的节点模型、属性面板、主画布与缩略图渲染。

## 待添加

- 页面过渡动画：定义可选过渡、时长和关闭方式，并接入预览翻页。
- 视频节点：已有 `packages/leafer-x-video-player` 插件原型和单测；尚未接入画布节点类型、保存/加载、属性面板及缩略图策略。
- 音频能力：明确是画布内音频节点、页面配音还是演示背景音，再选交互和存储方式。
- 截图/图片导出：确定导出范围、格式、分辨率、透明背景和多页行为。
- 导入与导出：先定义画布 JSON 版本与兼容策略，再扩展 PNG/JPEG 等交付格式。
- PSD 解析：明确图层、文字、蒙版、效果及智能对象的支持范围和不支持项。
- 本地模型与 RAG、AI 对话、AI 绘制：先定义模型运行环境、隐私边界、资源需求和可验收的工作流。
- 预览触控手势：补充平移、缩放、多点触控及输入设备冲突处理；详见 `docs/preview-page-plan.md`。

## 条件性技术工作

- 大规模渲染优化：先确定真实数据规模、元素类型和交互要求，再建立性能基准；满足瓶颈条件后再做视口裁剪、空间索引或数据渲染层。方案见 `docs/leafer-large-scale-render-optimization.md`。

## 产品方向探索

- 数学教师 2D/3D 讲课软件：首期聚焦初高中空间几何、函数曲面、数学公式和分步演示。先完成教师访谈和交互原型，再拆分正式开发任务；规划见 `docs/3d-math-teaching-software-plan.md`。
