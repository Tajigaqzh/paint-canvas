# 预览页现状与后续规划

## 当前实现

预览页位于 `/preview`，复用制作页 `useLeaferCanvas` 渲染当前画布文档。制作内容只读；预览批注写入共享的 `canvasStore`，并使用 `source: "preview"` 与制作笔迹区分。离开预览页时清理所有页面的预览批注，因此批注不是独立副本，也不会作为作品内容保留。

当前已支持：

- 画笔批注，可调整颜色和粗细；橡皮擦只修改 `source: "preview"` 的笔迹。
- 鼠标选择模式、放大镜、批注清除，以及离开页面时清理批注。
- 多页缩略图切换、键盘左右翻页；切页时重播当前页动画。
- 手动重播动画、自动轮播及间隔设置、全屏、工具栏和页面条收起。
- 只读画布内容，预览页不展示标尺。

## 设计约束

- 预览与制作共用画布渲染引擎和后端加载的当前文档，不创建文档副本。
- `source: "preview"` 是预览批注的边界。新增清除或擦除行为时不得影响 `source: "brush"` 制作笔迹或普通素材线条。
- 离开预览页会清理预览批注；如果未来需要保存演示批注，应先定义独立持久化模型，不能直接取消清理。
- 新增节点能力时，应确认预览复用的渲染映射能够正确展示该节点。

## 待添加

- 触控手势：平移、缩放及多点触控行为；需验证桌面触控屏和移动浏览器上的交互冲突。
- 页面过渡效果：先确定支持的过渡类型、是否可关闭，以及动画时长配置。
- 更完整的演示控制：例如逐页动画编排或演示配置持久化，需结合页面过渡一起评估。

早期方案曾提出本地副本、预览专属文档状态及新增 `/preview` 路由。这些已不符合当前实现，不应作为后续实现依据。
